# Кондитерское ателье

Каталог десертов и двухшаговая форма заявки на бесплатную дегустацию. Учебный проект на React с исходной сборкой Webpack.

## Назначение

Владелец кофейни или закупщик выбирает десерты для витрины и оставляет заявку на дегустацию. Компонент помогает передать интересующие позиции и контакты в одном сценарии.

## Сценарий

1. Отфильтровать 12 позиций по ассортименту, категории или отметке «Выбирают сети».
2. Добавить позиции кнопками «В набор». Повторное нажатие убирает позицию.
3. Нажать «Оформить» или «Дегустация». Можно открыть форму и без набора.
4. Выбрать одну или несколько целей. Кнопка «Далее» доступна, когда выбрана хотя бы одна.
5. Указать имя, заведение, город, количество точек и телефон, отметить согласие. Комментарий необязателен.
6. Отправить форму. При ошибке появляется подсказка, фокус переходит к первому неверному полю. После успешной проверки показывается демонстрационное подтверждение, набор очищается.

Отправка имитируется задержкой 900 мс. Сервера нет: контакты не передаются, не сохраняются в браузере и не выводятся в консоль. Уведомление менеджеру не отправляется.

Форма закрывается крестиком, клавишей Escape или нажатием на затемнение. При открытии блокируется прокрутка страницы; фокус остаётся внутри диалога и возвращается после закрытия.

## Запуск в VS Code

Требуется Node.js 20.19+ (можно использовать Node.js 24).

Откройте папку проекта в VS Code, затем в меню «Терминал → Создать терминал»:

```sh
npm ci
npm start
```

Адрес локального сайта появится в терминале. Чтобы остановить сервер, нажмите Ctrl+C.

## Сборка и GitHub Pages

```sh
npm run build
```

Webpack создаёт папку `docs` с HTML, CSS, JavaScript и изображениями. Пути относительные, поэтому страница работает в подпапке `/atele/`.

После загрузки исходников и `docs` в ветку `main`: Settings → Pages → Deploy from a branch → ветка `main`, папка `/docs` → Save. Статус публикации и рабочая ссылка появятся в Pages. Ссылку прототипа перед просмотром следует проверить в режиме Present в Figma.

## Устройство проекта

- `src/app/App.jsx` — каталог, фильтры, выбранный набор и открытие формы.
- `src/app/data.js` — товары, цели и этапы сотрудничества.
- `src/app/components/RequestForm.jsx` — состояние формы, переходы, проверка и имитация отправки.
- `StepGoal.jsx`, `StepContacts.jsx`, `Success.jsx` — содержимое трёх экранов.
- `Field.jsx` — поле с подписью и доступным сообщением об ошибке.
- `src/app/utils.js` — форматирование телефона, проверка полей и склонение слова «позиция».
- `src/app/form.css`, `catalog.css` — стили и адаптив.
- `config/` — исходная учебная конфигурация Webpack, адаптированная для одной React-страницы.

`App` хранит идентификаторы выбранных товаров через `useState` и передаёт полные данные в форму через props. `RequestForm` хранит текущий шаг, цели, контакты, ошибки и состояние отправки. Изменения выполняются через обработчики событий. Отфильтрованный каталог вычисляется из массива товаров при рендере.

Макет перенесён в обычный CSS без библиотеки интерфейса. На планшете карточки переходят в две колонки, на узком телефоне — в одну. Форма ограничена высотой окна и прокручивается. В демо реализован сокращённый каталог: 12 позиций вместо полного ассортимента макета; страницы производства и другие разделы сайта не входят в работу.

## Использование нейросетей

Использовался OpenAI Codex: для чтения параметров макета через Figma, помощи с React-компонентами и CSS, настройкой сборки, проверкой сценария и подготовкой документации. Это помогло связать каталог с формой и проверить адаптив. Дизайн и фотографии взяты из предоставленного макета, новые изображения нейросетью не создавались.
